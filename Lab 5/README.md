# Lab 5 – Multiclass Classification

## Course
- Course Code: CSET343
- Course Name: AI in Healthcare
- Semester: VII
- Year: 4th Year

## Objective
To implement and evaluate multiclass machine learning classification models using a medical dataset.

## Dataset
Dermatology Dataset.

The target variable represents six different skin diseases:
- 1 – Psoriasis
- 2 – Seborrheic dermatitis
- 3 – Lichen planus
- 4 – Pityriasis rosea
- 5 – Chronic dermatitis
- 6 – Pityriasis rubra pilaris

## Tasks Performed
1. Loaded and explored the dataset.
2. Calculated summary statistics.
3. Checked missing values and duplicate records.
4. Handled missing values using median imputation.
5. Visualized class distribution and feature distributions.
6. Created a correlation heatmap.
7. Split the dataset into training and testing sets using stratified sampling.
8. Standardized features where required.
9. Implemented four multiclass ML algorithms:
   - KNN
   - Random Forest
   - Logistic Regression
   - SVM
10. Evaluated the models using:
   - Accuracy
   - Precision
   - Recall
   - F1-score
   - Confusion Matrix
   - ROC-AUC

## Conclusion
The performance of multiple multiclass classification algorithms was compared on the Dermatology dataset. The model results were evaluated using classification metrics and confusion matrices to determine their effectiveness in classifying different skin diseases.

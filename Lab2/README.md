## Objective

The objective of this lab is to perform data cleaning and enrichment on a sample clinical dataset with missing values.

The Heart Failure Clinical Records Dataset is used for the experiment.

---

## Dataset

### Heart Failure Clinical Records Dataset

The Heart Failure Clinical Records Dataset contains clinical records of heart failure patients.

The dataset includes features such as:

- Age
- Anaemia
- Creatinine Phosphokinase
- Diabetes
- Ejection Fraction
- High Blood Pressure
- Platelets
- Serum Creatinine
- Serum Sodium
- Sex
- Smoking
- Time
- DEATH_EVENT

The dataset is used to demonstrate healthcare data cleaning, preprocessing, feature engineering, and analysis.

## Objective

The objective of this experiment is to implement a program to read and process different types of healthcare and scientific data in different formats.

The experiment covers:

- Tabular Data
- Textual Data
- Image Data
- Signal Data
- Medical Data

---

## Dataset Used

### 1. Cleveland Heart Disease Dataset

The Cleveland Heart Disease Dataset is used for tabular and medical data ingestion.

The dataset contains patient-related attributes such as:

- Age
- Sex
- Chest Pain Type
- Resting Blood Pressure
- Cholesterol
- Fasting Blood Sugar
- Resting ECG Results
- Maximum Heart Rate
- Exercise-Induced Angina
- ST Depression

The dataset is commonly used for heart disease prediction and medical data analysis.

### 2. MIT-BIH Arrhythmia Database

The MIT-BIH Arrhythmia Database is used for ECG signal data.

The database contains ECG recordings along with expert annotations for arrhythmias.

The `wfdb` Python library is used to access and process the ECG recordings.
